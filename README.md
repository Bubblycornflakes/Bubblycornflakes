I build things that run on my own machine, and I try to measure whether they actually work.

## What I'm working on

### 🎙️ J.A.R.V.I.S.: a local voice assistant for macOS
Say "Hey Jarvis" and a local language model decides what to do, uses tools to do it, and answers out loud.

- Local language model (Ollama) with tool calling, plus a fast lane that handles simple commands without the model
- Speech in with Whisper, speech out with Kokoro, a small HUD window to watch it work
- Controls apps, music, volume, smart lights, reminders, to-dos, weather and journey times
- A tool-selection evaluation harness: a small local model (qwen3:4b) picks the right tool on 95% of 43 labelled requests, up from 86% after I fixed the tool descriptions

**[→ See the project](https://github.com/Bubblycornflakes/jarvis-local-voice-assistant)**

## What I'm learning

- How tool-using agents fail, and how to fix them with clearer tool descriptions instead of guessing
- Running small language models locally and comparing them on speed and accuracy
- Turning a personal project into something other people can read, run and trust
